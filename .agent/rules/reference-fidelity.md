# Rule: Reference Fidelity

1. **Research is the Ground Truth:** Every layout, text node, color hex code, and typography decision must match the verified documentation in `research/`.
2. **Never Redesign:** Do not alter the aesthetic or UX. Do not "fix" quirky storybook design choices present on the reference website.
3. **Never Skip Sections or Routes:** Every route in `research/COMPLETE_SITEMAP.md` and every section in `research/SECTION_ORDER_MAP.md` must be reproduced.
4. **No Fabricated Content:** All puppy names, prices, tags, phone numbers, and FAQ answers must be the actual content extracted from the reference site.
5. **Exact Sequencing:** DOM elements must follow the exact order mapped in `research/SECTION_ORDER_MAP.md`.
